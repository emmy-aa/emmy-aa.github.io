## Featured Project

### Home SOC Lab

My first featured cybersecurity project is a **Home Security Operations Center (SOC) Lab** built in a virtualized environment using:

* **Windows 11**
* **Ubuntu Server** (used to deploy and manage **Wazuh SIEM**)
* **Kali Linux** (for security testing and offensive security tools)

This project demonstrates my ability to build and configure a cybersecurity lab from the ground up, deploy a SIEM solution, connect multiple virtual machines, troubleshoot installation and networking issues, and document the entire process. The project includes configuration files, screenshots, implementation notes, and a detailed walkthrough of the environment.

As I continue developing my cybersecurity skills, I'll be adding more lab projects covering areas such as detection engineering, threat hunting, digital forensics, cloud security, and automation.
